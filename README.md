# Student Performance Prediction ML Project

## Overview
This project uses Machine Learning to predict student exam scores based on academic, personal and behavioral factors.

## Dataset
Student Performance Factors Dataset

## Features Used
- Hours Studied
- Attendance
- Previous Scores
- Sleep Hours
- Motivation Level
- Parental Involvement
- Internet Access
- Teacher Quality

## Machine Learning Models
- Linear Regression
- Random Forest Regressor

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R2 Score

## Result
The model predicts student's final exam score based on given factors.
